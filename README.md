## About Me

I am a developer on the path to software engineering and full-stack development. I focus on building practical products that solve real problems, and I work across the development cycle—from the first idea and planning to application logic, database design, testing, and ongoing improvement.

So far my work includes Telegram bots, search and monitoring tools, and automation scripts. That gave me hands-on experience with backend logic, databases, background jobs, notifications, quotas, and working within external API rate limits. I am now extending this foundation into web development.

My priorities are straightforward: reliable software, clean structure, safe handling of tokens and keys, good performance, and thorough testing. I work together with AI coding tools, but I read, test, and verify the code before it ships.
